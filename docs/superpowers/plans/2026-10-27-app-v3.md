# App v3 (tablero, Claude, ⌘K, cliente, actas, equipo) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir en la app de escritorio lo aprobado en las maquetas v3.

**Architecture:** Todo es UI sobre el repo de markdown (`app/ui`). Cada dato nuevo vive en un archivo:
- etiquetas, comentarios y checklist en el `.md` de la tarea;
- el catálogo de etiquetas en `equipo/etiquetas.md`;
- `revisada` en el acta.

La lógica pura va en `app/ui/datos/*.ts`, con pruebas Vitest. Los componentes la usan. El shell solo suma `chatAbierto` a la config local.

**Tech Stack:** Electron, React 19, TypeScript strict, Vite, Vitest, `yaml`, `lucide-react` 1.62.0 (ya instalado), pnpm.

**Spec:** maquetas aprobadas `docs/superpowers/specs/mockups-app/v3-tablero.html`, `v3-claude.html` y `v3-cliente.html`, más el spec base `docs/superpowers/specs/2026-10-27-app-escritorio-design.md`. Lo que las maquetas muestran es el comportamiento pedido. El texto bajo cada marco (`<small>`) son las reglas.

## Global Constraints

- **Textos visibles:** en español de Chile, tú, sin voseo.
- **Atajos:** toda acción con atajo tiene también su botón visible, y ese botón muestra el atajo (`⌘K`, `⌘J`, `⌘N`, letras del menú ⋯).
- **Sin animación** al abrir algo con teclado (⌘K, ⌘J, menús por tecla).
- **Botones:** `:active` con `scale(0.97)`.
- **Popovers:** `transform-origin` desde su disparador.
- **Colores:** solo tokens de `app/ui/tokens.css` y `app/ui/app.css`. Nada de hex nuevos en componentes.
- **Íconos:** `lucide-react`, `size={16}` (`ICONO` exportado por `ui/componentes/Lateral.tsx`), con `aria-hidden`.
- **Accesibilidad (WCAG 2.2 AA):**
  - texto interactivo de 14px o más;
  - `:focus-visible` con 2px de `var(--foco)`;
  - `<label>` reales;
  - Escape cierra menús, paletas y formularios;
  - el estado nunca se indica solo con color.
- **Escritura de archivos:** se relee antes de escribir. Para frontmatter, `cambiar(ruta, cambios)` de `ui/datos/md.ts`; para cuerpos, `repo.read`, luego cambiar el texto, luego `repo.write`.
- **Marcas de tiempo nuevas** (comentarios): UTC, `YYYY-MM-DDTHH:MMZ`.
- **Borrar:** la app solo borra cuando una persona lo confirma. Nada se borra solo.
- **Al tocar `app/ui`:** `pnpm --dir app build:ui` y commitear `app/ui-dist/` en el mismo commit (`CLAUDE.md`).
- **Verificación:** `pnpm --dir app test` (typecheck estricto + vitest) y `pnpm --dir app smoke` en verde antes de cada commit.
- **Tamaños:** archivos de 400 líneas o menos, funciones de 50 o menos. Si un archivo existente pasa el límite, se parte.

## Review Focus

1. **Títulos con `:`, comillas o `#`** en la tarea rápida: el YAML queda válido y el título intacto (T1, `archivoNueva`).
2. **Dos tareas con el mismo título el mismo día:** no se pisan, la segunda lleva sufijo `-2` (T1, `rutaNueva`).
3. **Comentario con saltos de línea o con "·":** queda como un solo comentario legible (T1, `agregarComentario` y `comentarios`).
4. **Casillas fuera de `## Checklist`** (por ejemplo `## Promesas` del acta): marcar la checklist no las toca (T1, `alternarCasilla`).
5. **Acta sin tareas enlazadas:** se puede confirmar igual y queda `revisada: true` (T7).
6. **Búsqueda sin tildes:** "cotizacion" encuentra "Cotización" (T5, `buscar`).
